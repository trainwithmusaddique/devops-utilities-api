# Internal DevOps Utilities API

## Aim

This Project aims to deliver Production grade 
Utilities APIs to Internal teams

- AWS Resources APIs
- Matrics
- Log Analysis

## Usage

    'git clone <>'

### Setup Python EnvironmentVV
    python -m venv musa
    source musa/bin/activate

### Install Requirements
    pip install -r requirements.txt

### Run Application
    python main.py
